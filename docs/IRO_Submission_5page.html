1. SOFTWARE REQUIREMENTS SPECIFICATION (SRS)

1.1 Purpose and Scope

IRO is a web-based outlet through which AAUA students and indigenes of Akungba, Iwaro, Etioro, Ayegunle and neighbouring communities report issues that affect town–gown relations (rent, security, land, harassment, festivals, sanitation, utilities, transport, prices). Today such issues go through scattered informal channels, many are never reported for fear of victimisation, and reporters rarely learn the outcome. IRO lets anyone submit a report (anonymously if they wish), gives each report a ticket ID for tracking, and gives an IRO desk officer a dashboard to review, escalate and resolve reports with a logged history. SMS alerts, file uploads, a server database and Yoruba translation are outside the scope of this version.

1.2 Users

UserRole
Student / Indigene (Reporter)Submits and tracks reports. Students may give a matric number; indigenes select their community.
IRO Desk Officer (Admin)Logs in, views statistics, filters reports, updates status, escalates and deletes reports.
Escalation AuthorityStudents' Affairs, community leaders (Oba/Baale) or police; receives escalated cases offline.

1.3 Major Components and their Interaction

ComponentFile(s)Responsibility
Pages (UI)index, report, track, admin .html; style.cssHome & guidelines, report form, tracking page, admin desk.
ReportFormjs/report.jsShows student/indigene fields, validates input, calls IssueStore.create(), shows ticket ID.
Trackerjs/track.jsCalls IssueStore.findById(); shows status and history without personal data.
AdminDeskjs/admin.jsLogin, statistics, search/filter, detail view, status update, escalation, deletion.
IssueStorejs/store.jsThe only data access point: create, find, update status, remove, stats, ticket IDs.
StorageBrowser localStorageHolds all issues as JSON (to be replaced by a server database later).

Interaction: Reporter → report.html → ReportForm.validate() → IssueStore.create() → localStorage → ticket ID shown. Reporter → track.html → Tracker → IssueStore.findById() → status + history shown. Desk Officer → admin.html → AdminDesk → IssueStore.updateStatus() (Submitted → Under Review → Escalated → Resolved → Closed, each change logged with time and note) → reporter sees the update when tracking. Escalated cases are forwarded to the Escalation Authority.

1.4 Constraints and Assumptions

Plain HTML5/CSS3/JavaScript, no frameworks; runs in any modern browser with no installation. Data is kept in the browser, so reports stay on the device used. Personal data must be handled in line with the Nigeria Data Protection Act 2023. Assumes the university and community leaders agree to act on escalated reports.

1.5 Functional Requirements

IDThe system shall…
FR-01display IRO's purpose, the reporting steps, issue categories and an emergency notice on the home page.
FR-02require the reporter to choose Student, Indigene or Other.
FR-03show an optional matric-number field for students and a required community list (Akungba, Iwaro, Etioro, Ayegunle, Oke-Oka, Other) for indigenes.
FR-04allow anonymous reporting; name and contact are then hidden and not stored.
FR-05capture category, severity (Low/Medium/High/Emergency), location, incident date, title and description.
FR-06reject invalid input with a clear message (missing fields, future date, short title/description, bad phone/e-mail).
FR-07create a unique ticket ID (IRO-YY-XXXXX), set status to Submitted and show the ticket with a tracking link.
FR-08let anyone track a report by ticket ID and see its status and history, without showing personal details.
FR-09restrict the admin desk to users with the correct passcode.
FR-10show total, open, emergency and resolved report counts.
FR-11list reports newest first, with search (ticket, title, location) and filters (status, category, reporter type).
FR-12let the officer view full details, change status with a note (timestamped history), escalate, and delete after confirmation.

NFR-07MaintainabilityAll data access goes through IssueStore; lists are configured in one IRO object; code is commented.
NFR-08PortabilityRuns in current Chrome, Firefox, Edge and Safari with no installation.
NFR-09Legal / ethicalComplies with the NDPA 2023; wording treats students and indigenes equally.
