IRO – Issues Reporting Outlet: Object Listing

CSC426 Weekly Dev – Weekend 3 · Joshua Omolafe · Matric No. 220404244

IRO is written in plain JavaScript as a small set of singleton objects. Each page has one controller object, and all of them share the configuration object IRO and the data-layer object IssueStore. The tables below list every object with its properties and methods.

1. Object summary

ObjectFileKindUsed byPurpose
IROjs/store.jsConfigurationAll pagesConstant lists and settings.
IssueStorejs/store.jsData layerAll controllersCreate, read, update and delete issues; statistics.
Helper functionsjs/store.jsUtilitiesAll controllersEscaping, date formatting, badges, filling selects.
ReportFormjs/report.jsControllerreport.htmlReport submission.
Trackerjs/track.jsControllertrack.htmlStatus tracking by ticket ID.
AdminDeskjs/admin.jsControlleradmin.htmlDesk officer dashboard.
Issue(data record)EntityIssueStoreOne reported issue stored in localStorage.

2. IRO (configuration object)

PropertyTypeValue / description
STORAGE_KEYString"iro_issues" – localStorage key holding all issues.
ADMIN_PASSCODEString"iro2026" – demo passcode for the admin desk.
CATEGORIESArray<String>10 issue categories (Security / Safety … Other).
COMMUNITIESArray<String>Akungba, Iwaro, Etioro, Ayegunle, Oke-Oka, Other.
STATUSESArray<String>Submitted, Under Review, Escalated, Resolved, Closed.
SEVERITIESArray<String>Low, Medium, High, Emergency.

3. IssueStore (data-layer object)

MethodReturnsDescription
getAll()Array<Issue>Reads all issues from localStorage, newest first; returns [] if data is missing or corrupt.
saveAll(list)voidWrites the whole list back to localStorage as JSON.
generateId()StringBuilds a unique ticket ID IRO-YY-XXXXX from an unambiguous alphabet.
create(data)IssueBuilds an Issue from form data (drops name/contact if anonymous), sets status Submitted with first history entry, saves it.
findById(id)Issue | nullCase-insensitive lookup by ticket ID.
updateStatus(id, status, note)Issue | nullSets the new status and appends {status, note, at} to history.
remove(id)voidDeletes an issue.
stats()Object{ total, open, emergency, byStatus } for the dashboard.

4. Helper functions (global)

FunctionReturnsDescription
escapeHtml(str)StringReplaces & < > " ' with HTML entities to prevent XSS.
formatDate(iso)StringFormats an ISO date, e.g. "7 Jul 2026, 14:05".
statusBadge(status)String (HTML)Coloured badge markup for a status.
fillSelect(select, items, placeholder)voidFills a <select> with option elements.

5. ReportForm (controller for report.html)

MemberTypeDescription
formHTMLFormElementThe #reportForm element.
el(id)FunctionShortcut for document.getElementById.
init()MethodFills drop-downs, sets the max date, attaches event listeners.
toggleReporterFields()MethodShows matric field for students, community list for indigenes.
toggleIdentity()MethodHides name/contact when Anonymous is ticked.
collect()Method → ObjectReads every form field into a plain object.
validate(d)Method → StringReturns an error message, or "" if valid.
submit(e)MethodValidates, calls IssueStore.create(), shows the ticket ID.

6. Tracker (controller for track.html)

MemberTypeDescription
el(id)FunctionShortcut for document.getElementById.
init()MethodAttaches the form handler; auto-tracks an ?id= in the URL.
show(id)MethodFinds the issue and renders title, meta, status and history (no personal data).

7. AdminDesk (controller for admin.html)

MemberTypeDescription
SESSION_KEYString"iro_admin" – sessionStorage flag for a logged-in officer.
selectedIdString | nullTicket ID of the report open in the detail panel.
el(id)FunctionShortcut for document.getElementById.
init()MethodFills filters, attaches listeners, restores an existing session.
login(e) / logout()MethodChecks passcode and opens the dashboard / ends the session.
showDashboard()MethodHides login card, shows dashboard, renders data.
filtered()Method → ArrayIssues matching search text and status/category/reporter filters.
render()MethodUpdates statistics cards and the report table.
openDetail(id)MethodShows full report details, reporter identity and history.
saveUpdate(e)MethodCalls IssueStore.updateStatus() with the chosen status and note.
deleteSelected()MethodConfirms, then deletes the open report.

8. Issue (data record)

PropertyTypeDescription
idStringTicket ID.
reporterTypeStringStudent | Indigene | Other.
anonymousBooleanReporter chose anonymity.
name, contactStringEmpty when anonymous.
matricNo, communityStringStudent matric number / indigene community.
category, severityStringFrom IRO.CATEGORIES / IRO.SEVERITIES.
location, incidentDateStringWhere and when (YYYY-MM-DD).
title, descriptionStringSummary and full account.
statusStringCurrent status.
createdAtString (ISO)Submission time.
historyArray<{status, note, at}>Append-only status log.
